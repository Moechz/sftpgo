Privacy Policy — SFTPGo for TerraMaster TOS

Applies to the community package of SFTPGo distributed via the TOS App Center. Last updated: 2026-09.

Summary

This package is fully offline at install and runtime by default. Neither the installer scripts nor the packaged application perform telemetry, analytics, crash reporting, or any outbound network request on their own.

What we do not collect

  • No usage statistics, no device fingerprints, no analytics.
  • No crash reports or error reports are sent anywhere.
  • No account data, file metadata, or transfer logs leave your NAS.
  • The installer never downloads anything: the complete application ships inside the package (store review category “online installation” does not apply).

Where your data lives

  • Accounts (including the initial administrator), virtual users, event rules and other configuration are stored in a local SQLite database: /var/lib/sftpgo/sftpgo.db.
  • Uploaded files are stored on the local filesystem paths you configure (TOS shared folders) or in cloud backends you explicitly configure yourself.
  • The initial administrator credential file is stored with root-only permissions at /var/lib/sftpgo/INITIAL_ADMIN_CREDENTIALS.txt and may be deleted after first login.

Optional features you control

SFTPGo supports optional outbound integrations (SMTP email notifications, webhooks / event actions, OpenID Connect, cloud storage backends, ACME certificates). All of them are disabled by default and only become active if the administrator configures them. When enabled, they connect only to the endpoints you specify.

Third-party software

The package redistributes the official SFTPGo release binaries and web assets built by the upstream project (AGPL-3.0, github.com/drakkan/sftpgo). License texts are included in the package (/usr/share/doc/sftpgo/).
